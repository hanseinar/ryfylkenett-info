# ryfylkenett-info
Informasjonsside for Ryfylkenett – Meshtastic-nettverk i Ryfylke

## Sider

- `index.html`: informasjon om Ryfylkenett (QR-kode på nodene)
- `t1000e.html`: oppdatering av SenseCAP T1000-E til Ryfylkenett-firmware (31,25 kHz). Firmwarefilen ligger som Release i `hanseinar/firmware`. Ved ny versjon oppdateres `FW_VERSION`, `FW_FILE` og `FW_URL` i siden.
